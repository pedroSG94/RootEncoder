Vp9ColorSpace

enum Vp9ColorSpace : Enum<Vp9ColorSpace>

VP9 color spaces defined in VP9 Bitstream & Decoding Process Specification, section 6.2.2.

The bitstream only signals this 3 bits value but VPCodecConfigurationRecord requires the three ISO/IEC 23001-8 codes, so each color space is mapped to its equivalent combination. UNKNOWN and RESERVED are mapped to 2 (unspecified).
